# Web Studio Landing Page

A responsive landing page for a fictional web studio, built as a markup homework project.

## Overview

This project includes a modern single-page landing site with:
- responsive layout and navigation
- mobile menu toggle
- call-to-action modal form
- team section with social links
- portfolio section with responsive images
- footer subscription form

## Files

- `index.html` — main HTML page
- `css/styles.css` — styles for layout, typography, responsive behavior, and components
- `js/mobile-menu.js` — mobile menu open/close functionality
- `js/modal.js` — modal dialog open/close functionality
- `images/` — image assets used for portfolio, team, and icons
- `prettierc.json` — Prettier formatting configuration

## Features

- Mobile-friendly navigation menu with open/close controls
- Modal contact form triggered by the hero section button
- Highlight cards for studio advantages
- Team section with profile cards and social icons
- Portfolio cards with responsive `picture` sources
- Smooth visuals and modern layout powered by CSS

## Usage

1. Open `index.html` in a web browser.
2. Click the burger icon to open the mobile menu.
3. Click `Order Service` to open the contact modal.

## Notes

- The form fields and links are placeholders for demonstration.
- No build tools or package managers are required.
